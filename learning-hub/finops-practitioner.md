## 🎯 Goal

Master cloud cost management as an engineering discipline. Learn to build automated cost governance, optimization strategies, and chargeback systems that align Finance and Engineering.

---

## 📚 Learning Modules

### Module 1: FinOps Foundations (Week 1-2)
- [ ] FinOps principles: Inform, Optimize, Operate
- [ ] FinOps lifecycle: Crawl → Walk → Run
- [ ] Cloud billing models: on-demand, reserved, spot, savings plans
- [ ] FinOps team structure and stakeholders
- [ ] Unit economics: cost per transaction, cost per customer
- **Lab**: Analyze an AWS Cost & Usage Report, identify top 5 waste areas

### Module 2: Cloud Cost Visibility (Week 3-4)
- [ ] AWS Cost Explorer, Azure Cost Management, GCP Billing
- [ ] Tagging strategies for cost allocation
- [ ] Showback vs Chargeback models
- [ ] Cost allocation to teams/projects/environments
- [ ] Building cost dashboards (Grafana, custom)
- **Lab**: Implement tagging strategy + Grafana cost dashboard for multi-team org

### Module 3: Optimization Strategies (Week 5-6)
- [ ] Rightsizing: compute, storage, database instances
- [ ] Reserved Instances vs Savings Plans — when to use which
- [ ] Spot instance strategies (interruption handling, diversification)
- [ ] Storage optimization (lifecycle policies, tiering)
- [ ] Network cost optimization (NAT Gateway, data transfer)
- **Lab**: Build rightsizing recommendation engine with Python + AWS API

### Module 4: Automation & Governance (Week 7-8)
- [ ] Automated idle resource detection and cleanup
- [ ] Scheduling: stop dev/staging outside business hours
- [ ] Budget alerts and anomaly detection
- [ ] Policy-as-Code for cost guardrails (prevent oversized instances)
- [ ] CI/CD cost estimation (Infracost integration)
- **Lab**: Lambda functions for automated resource scheduling + anomaly alerts

### Module 5: Advanced & Certification (Week 9-10)
- [ ] Multi-cloud cost management strategies
- [ ] Kubernetes cost management (Kubecost, OpenCost)
- [ ] AI/ML workload cost optimization (GPU scheduling)
- [ ] FinOps for containers and serverless
- [ ] FinOps Certified Practitioner exam prep
- **Lab**: Deploy Kubecost on K8s cluster, build team-level cost reports
